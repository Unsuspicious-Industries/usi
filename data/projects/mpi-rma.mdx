MPI one-sided communication lets a process write into a peer's memory window. mpi-rma puts a typed Rust API over rsmpi and adds a ring transport. Payloads go into pre-allocated slots, polling reads local memory, and no sender waits for the receiver.

Safe mode gates the sender with an acknowledgement counter, and a send that would overwrite an unread slot fails with `Error::Full`. Raw mode never refuses. It overwrites and reports the gap through `lost()`. Each slot carries a sequence, a length and a CRC32, so loss and corruption are visible.
